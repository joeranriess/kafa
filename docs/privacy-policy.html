Kleinanzeigen Anti Fraud Assistant

Privacy Policy — Last updated: August 2026

Short version: Your API key is stored locally on your device. Conversation text is sent directly to the AI provider you choose during analysis and nowhere else. The extension developer receives no data whatsoever.

What this extension does

Kleinanzeigen Anti Fraud Assistant is a Chrome extension that helps users of kleinanzeigen.de assess whether a conversation shows signs of fraud. It sends the text of the current conversation to an AI provider of your choice (Claude, OpenAI, or OpenRouter) and displays the result locally.

Data we collect

Nothing. The extension developer does not operate any server, collect any analytics, or receive any data from your browser.

Data stored on your device

The extension stores the following in chrome.storage.local, which is private to your browser profile and never synced:

  • Your API key for the selected AI provider
  • Your selected AI provider and model
  • Your Workspace ID (optional, Claude only)

This data never leaves your device except as part of authenticated API calls to the provider you configured.

Data sent to AI providers

When you click "Konversation prüfen", the extension sends the following to your chosen AI provider:

  • The text content of the current Kleinanzeigen conversation
  • Publicly visible profile information of the other party (account age, if available)

This request is made directly from your browser to the provider's API using your own API key. The provider's own privacy policy applies to how they handle this data.

  • Anthropic (Claude): anthropic.com/privacy
  • OpenAI: openai.com/privacy
  • OpenRouter: openrouter.ai/privacy

Permissions used

  • storage — to save your API key and settings locally
  • Host access to kleinanzeigen.de — to read the conversation text shown on the page
  • Host access to api.anthropic.com, api.openai.com, openrouter.ai — to make API calls to the AI provider you configured

Third-party services

The extension does not use any analytics, crash reporting, or telemetry services. No third-party code is loaded from external sources at runtime.

Children's privacy

This extension is not directed at anyone under the age of 16 and does not knowingly collect data from minors.

Changes to this policy

If this policy changes materially, the updated version will be published at this URL with a new date. Continued use of the extension after a change constitutes acceptance of the updated policy.
